# Native 3D Pac-Man C++ Engine

A native C++ / OpenGL implementation of classic 3D Pac-Man featuring real-time collision detection, continuous physics interpolation, ghost AI tracking, and dynamic lighting.

## 🚀 Building the Project

### Prerequisites
- **C++17 Compiler** (GCC, Clang, or MSVC)
- **CMake** (v3.10 or higher)
- **OpenGL Development Libraries**

### Build Commands

```bash
# 1. Clone the repository
git clone [https://github.com/your-username/3d-pacman.git](https://github.com/your-username/3d-pacman.git)
cd 3d-pacman

# 2. Create build folder
mkdir build && cd build

# 3. Generate Makefile and Compile
cmake ..
cmake --build .
